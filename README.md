# The Night at FIBO [คืนหลอนก่อนรุ่งสาง]
เราจะได้รับบทเป็น วิชัย อดีตช่างเทคนิคที่ตกงานจากสงครามน้ำมันที่กำลังดุเดือดในปัจจุบัน ทำให้เขาต้องหางานใหม่เพื่อแบกรับหนี้สินที่มีอยู่ ซึ่งงานใหม่ที่วิชัยได้รับคือ การเป็นพนักงานรักษาความปลอดภัยในช่วงเวลา 00.00 - 06.00 ที่ตึก FIBO แต่สิ่งที่เขาไม่รู้เลยว่าเบื้องหลังตึกที่เขาอยู่นี้ มีเบื้องลึกเบื้องหลังอะไรซ่อนอยู่บ้าง ทำให้ในคืนนี้เขาไม่เพียงแค่ต้องทำหน้าที่กกลางคืนเท่านั้น แต่ยังต้องเอาชีวิตรอดจากความไม่ปกติที่เกิดขึ้นในตึกแห่งนี้
## Overview
- แนวเกม : Anomaly Detection 
- จำนวนผู้เล่น : 1 คน [Single Player]
- Platform ที่ใช้รันเกม : Window PC (รันผ่าน VS Code)
- Tech Stack / Additional Library :
  - iostream แสดง OUTPUT ในหน้าจอ Terminal
  - vector เก็บรายชื่อห้องทั้งหมด และเก็บรายการ Anomaly ที่สุ่มเกิดขึ้นในแต่ละเทิร์น
  - string เอาไว้จัดการข้อความต่างๆ และที่อยู่ของไฟล์รูปภาพ
  - SFML : ไลบรารีหลักที่ใช้เปลี่ยนโค้ด C++ ธรรมดาให้กลายเป็นเกมแบบมีกราฟิก
  - Memory จัดการระบบเก็บข้อมูลแบบ Smart Pointer
## Rules
- **Objective** : ผู้เล่นต้องรับบทเป็นยามกะตึกที่จะต้องตรวจจับความผิดปกติที่เกิดขึ้นภายในตึก FIBO ซึ่งการเล่นแต่ละครั้ง จะเเบ่งออกเป็น 6 Turn 

- **ระบบความผิดปกติ** : ในเกมจะมีรอบ Turn 0 จะเป็นเวลาปลอดภัยให้ผู้เล่นจดจำสภาพห้องปกติ ส่วน Turn ที่ 1 เป็นต้นไป ระบบจะเริ่มสุ่มความผิดปกติในภาพ

- **ระบบการล็อคห้อง** : การใช้ล็อคห้องจะเป็นการป้องกับความผิดปกติ โดยการปิดตายพื้นที่ที่เกิดความผิดปกตินั้น และรายงานไปยังระบบส่วนกลางเพื่อจัดการกับความผิดปกติดังกล่าว  

- **เงื่อนไขการเเพ้** : ไม่ล็อคห้องที่มีความผิดปกติ โดยที่หากล็อคห้องไม่ตรงกับสถาณะห้องที่เกิดขึ้นจะแพ้เกม เช่น ห้องผิดปกติและไม่ล็อคห้อง = แพ้ , ห้องไม่ผิดปกติแต่ล็อค = แพ้
- **เงื่อนไขการชนะ** สามารถจัดการความผิดปกติได้หมดตั้งแต่เริ่มเกมจนจบ turn ที่ 6
# Game Manual
- **ช่วงที่ 1 การเริ่มเกม**
  - เมื่อเปิดเกมมา ระบบจะเเสดง Title ให้ผู้เล่นกดเริ่มเกม (Play) หรือกดออกเกม (Quit)
  - ระบบจะให้เรากรอกใบสมัครสำหรับการรับเข้าทำงาน โดยข้อมูลในใบสมัครจะมีการเลือกฐานเงินเดือน ปัญหาด้านหัวใจ และประสบการณ์การทำงาน ซึ่งจะมีผลกับความยากของสถานกาณ์และทรัพยากรที่มี
  - เมื่อยืนยันตำแหน่ง ระบบจะพาผู้เล่นเข้าสู่หน้าจอห้องควบคุม และเริ่มต้นกะการทำงานเทิร์นแรกที่เวลา 00:00 น. ทันที
- **ช่วงที่ 2 ระหว่างการทำงาน**
  - การสลับกล้อง : ผู้เล่นใช้เมาส์คลิ้กทำให้หน้าจอกล้องวงจรปิดจะสลับไปยังห้องต่างๆ ในตึก FIBO (Room Switching)
  - การตรวจหาความผิดปกติ : ผู้เล่นจะต้องจำภาพห้องตอนที่ยังอยู่ใน Turn 0 และหลังจากนั้นผู้เล่นจะต้องเทียบภาพห้องต่างๆ เพื่อหาความผิดปกติด้วยตนเอง
    - `กรณีที่ 1` : หากไม่เจอความผิดปกติใดๆ สามารถกดเลื่อนไปดูห้องอื่นๆ ได้ หรือถ้าหากไม่เจอความผิดปกติไม่เจอใน Turn นั้นแล้ว จะกดปุ่ม `SKIP` เพื่อ skip turn นั้นไปเลยก็ได้
    - `กรณีที่ 2` : หากเจอความผิดปกติ ผู้เล่นจะต้องกด `UNLOCKED` เพื่อเปลี่ยนเป็น `LOCKED` เพื่อป้อกันสิ่งผิดปกติที่เจอ 
- **ช่วงที่ 3 สรุปผล**
  - กรณีที่ 1 ผู้เล่นล็อคห้องไม่ตรงกับสถาณะห้องที่เกิดขึ้น
  - กรณีที่ 2 ผู้เล่นรอดชีวิต : จะเกิดขึ้นเมื่อผู้เล่นสามารถตรวจจับ Anomaly หรือว่าตรวจจับความผิดปกติได้ผิดพลาดที่ระบบเกมได้มีการกำหนดไว้ ได้จนครบ 6 turn
