# The Night at FIBO [คืนหลอนก่อนรุ่งสาง]
เราจะได้รับบทเป็น วิชัย อดีตช่างเทคนิคที่ตกงานจากสงครามน้ำมันที่กำลังดุเดือดในปัจจุบัน ทำให้เขาต้องหางานใหม่เพื่อแบกรับหนี้สินที่มีอยู่ ซึ่งงานใหม่ที่วิชัยได้รับคือ การเป็นพนักงานรักษาความปลอดภัยในช่วงเวลา 00.00 - 06.00 ที่ตึก FIBO แต่สิ่งที่เขาไม่รู้เลยว่าเบื้องหลังตึกที่เขาอยู่นี้ มีเบื้องลึกเบื้องหลังอะไรซ่อนอยู่บ้าง ทำให้ในคืนนี้เขาไม่เพียงแค่ต้องทำหน้าที่กกลางคืนเท่านั้น แต่ยังต้องเอาชีวิตรอดจากความไม่ปกติที่เกิดขึ้นในตึกแห่งนี้
## Overview
- แนวเกม : Anomaly Detection / Resource Management
- จำนวนผู้เล่น : 1 คน [Single Player]
- Platform ที่ใช้รันเกม : Window PC (รันผ่าน VS Code)
- Tech Stack / Additional Library :
  - iostream 
  - vector เก็บรายชื่อห้องทั้งหมด และเก็บรายการ Anomaly ที่สุ่มเกิดขึ้นในแต่ละเทิร์น
  - string เอาไว้จัดการข้อความต่างๆ และที่อยู่ของไฟล์รูปภาพ
  - ctime / cstdlib ใช้ทำระบบสุ่มจำนวน Anomaly ในแต่ละรอบของการเล่น และจำนวน Anomaly ในแต่ละ turn, ใช้ในการสุ่มเวลาในการเกิด Jumpscare
  - Conio ตรวจสอบการกดปุ่มต่างๆ ภายในเกม
  - Window เอาไว้พักหน้าจอ / เคลียร์หน้าขอ / แสดงผลของเกมบนหน้าจอ terminal อย่างต่อเนื่อง
  - SFML : ไลบรารีหลักที่ใช้เปลี่ยนโค้ด C++ ธรรมดาให้กลายเป็นเกมแบบมีกราฟิก
## Rules
- **Objective** : ผู้เล่นต้องรับบทเป็นยามกะตึกที่จะต้องตรวจจับความผิดปกติที่เกิดขึ้นภายในตึก FIBO ซึ่งการเล่นแต่ละครั้ง จะเเบ่งออกเป็น 6 Turn โดยที่แต่ละ Turn จะมีเวลาสำรวจความผิดปกติ 2 นาที

- **ระบบความผิดปกติ** : ในเกมจะมีรอบ Turn 0 จะเป็นเวลาปลอดภัยให้ผู้เล่นจดจำสภาพห้องปกติ ส่วน Turn ที่ 1 เป็นต้นไป ระบบจะเริ่มสุ่มความผิดปกติในภาพ ซึ่งความผิดปกติจะเกิดขึ้นมาจากการสุ่ม ซึ่งอัตราการเกิดความผิดปกติจะขึ้นอยู่กับความยากที่ผู้เล่นเลือก

- **ระบบการปิดประตู** : การใช้ประตูจะเป็นการป้องกับความผิดปกติ โดยการปิดตายพื้นที่ที่เกิดความผิดปกตินั้น และรายงานไปยังระบบส่วนกลางเพื่อจัดการกับความผิดปกติดังกล่าว ทุกครั้งที่ใช้งานจะเสียพลัง 1 หน่วย โดยจำนวนพลังงานที่มีในตอนเริ่มต้น จะขึ้นอยู่กับระดับความยากที่ผู้เล่นเลือก 

- **เงื่อนไขการเเพ้** : ไม่ล็อคประตูในห้องที่มีความผิดปกติมากเกินไป จนมีจำนวนการพลาดที่เกินกว่าที่ระบบกำหนดไว้ในตอนเริ่มเล่นแต่ละครั้ง (เป็นการสุ่มจำนวนโควตาอีกที) นอกจากนี้การใช้พลังงานในการปิดประตูมากเกินไปจนพลังงานหมดก่อนที่เกมจะจบก็จะยิ่งทำให้โอกาสการแพ้สูงมากขึ้น
- **เงื่อนไขการชนะ** สามารถบริหารการใช้พลังงานและจัดการความผิดปกติได้หมดตั้งแต่เริ่มเกมจนจบ turn ที่ 6
# Game Manual
- **ช่วงที่ 1 การเริ่มเกม**
  - เมื่อเปิดเกมมา ระบบจะเเสดง Title ให้ผู้เล่นกดเริ่มเกม (Play) หรือกดออกเกม (Quit)
  - ระบบจะให้เรากรอกใบสมัครสำหรับการรับเข้าทำงาน โดยข้อมูลในใบสมัครจะมีการเลือกฐานเงินเดือน ปัญหาด้านหัวใจ และประสบการณ์การทำงาน ซึ่งจะมีผลกับความยากของสถานกาณ์และทรัพยากรที่มี
  - เมื่อยืนยันตำแหน่ง ระบบจะพาผู้เล่นเข้าสู่หน้าจอห้องควบคุม และเริ่มต้นกะการทำงานเทิร์นแรกที่เวลา 00:00 น. ทันที
- **ช่วงที่ 2 ระหว่างการทำงาน**
  - การสลับกล้อง : ผู้เล่นกดปุ่ม `A` หรือ `D` ทำให้หน้าจอกล้องวงจรปิดจะสลับไปยังห้องต่างๆ ในตึก FIBO (Room Switching)
  - การตรวจหาความผิดปกติ : ผู้เล่นจะต้องจำภาพห้องตอนที่ยังอยู่ใน Turn 0 และหลังจากนั้นผู้เล่นจะต้องเทียบภาพห้องต่างๆ เพื่อหาความผิดปกติด้วยตนเอง
    - `กรณีที่ 1` : หากไม่เจอความผิดปกติใดๆ สามารถกดเลื่อนไปดูห้องอื่นๆ ได้ หรือถ้าหากไม่เจอความผิดปกติใน Turn นั้นเลย จะกดปุ่ม `S` เพื่อ skip turn นั้นไปเลยก็ได้
    - `กรณีที่ 2` : หากเจอความผิดปกติ ผู้เล่นจะต้องกด `F` เพื่อปิดประตูห้องที่เจอ และจะสูญเสียพลังงานในการปิดประตูทุกครั้ง จึงจะต้องบริหารการใช้พลังงานดีๆ เพื่อให้สามารถเล่นเกมได้จนจบ
- **ช่วงที่ 3 สรุปผล**
  - กรณีที่ 1 ผู้เล่นเสียชีวิต : จะเกิดขึ้นเมื่อผู้เล่นปล่อยให้มี Anomaly เหลืออยู่มากเกินไป จนเกินโควตาการพลาดที่ระบบเกมกำหนดไว้ก่อนเริ่ม Turn 0 ซึ่งจะทำให้ผู้เล่นเสียชีวิตก่อนจบเกม และจะทำให้เกมจบทันที
  - กรณีที่ 2 ผู้เล่นรอดชีวิต : จะเกิดขึ้นเมื่อผู้เล่นสามารถตรวจจับ Anomaly ได้ครับ หรือว่าตรวจจับความผิดปกติได้ผิดพลาดน้อยกว่าที่ระบบเกมได้มีการกำหนดไว้ หรือสามารถจัดการพลังงานให้เหลือพอสำหรับตรวจจับ Anomaly ได้จนครบ 6 turn ซึ่งกรณีฉากจบนี้ เราจะได้รับ certificate จากองค์กรที่จะรายงานผลการดำเนินงานของเรา รายละเอียดจะประกอบไปด้วย จำนวน Anomaly ที่มี, จำนวน Anomaly ที่เราตรวจจับได้ + จำนวนที่เราพลาด, การประเมินเกรดเพื่อสรุปคุณภาพการทำงาน โดยอ้างอิงจากสถิติการตรวจจับ Anomaly ที่เราทำได้
